# 💡 Kuldreeglid kukeseentega kokkamisel

1. **Puhasta õigesti!** Püüa seeni vee all mitte pesta, sest nad imavad vett nagu käsnad. Kasuta puhastamiseks spetsiaalset seenepintslit või majapidamispaberit.
2. **Auruta esmalt vesi välja.** Kui seened lähevad otse pannile, pane nad sinna *ilma rasvaineta*. Kuumuta seentest vesi välja ja alles siis, kui pann on kuiv, lisa rasvaine. Nii seened praevad, mitte ei kee omas mahlas.
3. **Või on seene parim sõber.** Õli sobib hästi, aga ehtsa või maitse muudab kukeseeneroad oluliselt rammusamaks ja paremaks.
