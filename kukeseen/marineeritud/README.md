# 💡 Reeglid seente marineerimisel

1. **Äädikas alati viimasena.** Äädikas lisa alles keetmise lõpus. Kui see pikalt keeb, aurustub happelisus ära ja purgid ei pruugi hästi säilida.
2. **Kasuta õiget soola.** Hoidistamisel tohib kasutada ainult tavalist jämedat (või peenikest) kivisoola või meresoola. **Jodeeritud sool** võib hoidised roiskuma ajada või maitse rikkuda.
3. **Steriliseeri hoolikalt.** Purkide ja kaante puhtus on pikaajalise säilivuse alus. Pese purgid korralikult ning kuumuta neid enne seente lisamist kas praeahjus (100 kraadi juures) või kalla keeva veega üle. Kaaned tuleks samuti läbi keeta.
